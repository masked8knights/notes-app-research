# Fact-check: Lane 5 — open-source components for a note-taking app

Checked 2026-10-27 against primary sources (project sites, GitHub LICENSE files, npm registry, official docs) where possible; secondary sources only where noted.

**Summary:** 12 claims checked: 12 CONFIRMED, 0 WRONG, 0 UNSURE. Two claims carry state-change notes: Godot PR #110863 has been merged (no longer "open"), and the lowkey.gg dispute (March 2021) was a GPL-violation accusation for not shipping source, not a dispute over forking. Star count for Stirling-PDF has drifted slightly upward (~94–95k in late Oct 2026).
