# Fact-check: note-taking apps (lane 3)

Summary: 47 sub-claims checked against primary sources (official pricing/docs, vendor blogs, GitHub repos with LICENSE files, app-store listings) on 2026-10-27. Verdicts: 33 CONFIRMED, 7 WRONG, 4 PARTLY (partially right), 3 UNSURE. Biggest errors: Miro's Trustpilot rating is ~2.3 not ~1.6 and its Enterprise plan has no public per-seat price; Tolaria is ~52K lines of Rust (not 100K) and has no released web client; AFFiNE Cloud does not claim E2EE; Heptabase starts at $8.99/mo, not $12.
