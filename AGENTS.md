# Assistant bootstrap

This folder is a long project run under a workflow playbook.

Before doing anything else, read project/PLAYBOOK.md and follow it. Every new
session cold-starts by reading, in order: project/PLAYBOOK.md, project/REQUIREMENTS.md,
project/MILESTONES.md, project/todo.md. Research lives in RESEARCH.md, FEATURES.md,
APPS-LINKS.md and research-material/. The folder, not the chat, is the project's
memory; do not act from chat memory alone.
